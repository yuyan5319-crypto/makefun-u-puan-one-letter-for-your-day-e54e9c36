One letter for my day, for make.fun's "One Letter for Your Day" bounty, $5 in USDC shared by the top letters.

> U — for "unhinged": a day that started with a plan and ended with none of it surviving contact with reality, in the best way.

## Run it

```sh
node main.ts
```

This writes the single letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
